SKILLMATCH V2 - PROYECTO CORREGIDO

Antes de desplegar:
1) Lee CAMBIOS_SKILLMATCH_V2.md.
2) Ejecuta backend/sql/09_skillmatch_v2_soft_skills.sql.
3) Ejecuta backend/sql/10_perfiles_profesionales.sql.
4) Configura CLOUDINARY_CLOUD_NAME, CLOUDINARY_API_KEY y CLOUDINARY_API_SECRET en produccion.
5) Ejecuta npm install en backend y frontend.
6) Prueba npm test / npm run build en una rama antes de fusionar a main.

No se incluyen node_modules para evitar subir cientos de MB de dependencias al repositorio.
